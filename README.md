# Rule Based Chatbot - DecodeLabs Project 1

simple chatbot using if-else logic, no ml/ai models involved

## setup

1. install deps:
```
pip install -r requirements.txt
```

2. rename `.env.example` to `.env` (or just edit the existing `.env`) and set your values

3. run it:
```
python main.py
```

## files

- `main.py` - the chatbot itself
- `.env` - config values (bot name, typing delay, debug mode)
- `.env.example` - template for the .env file
- `requirements.txt` - just needs python-dotenv
